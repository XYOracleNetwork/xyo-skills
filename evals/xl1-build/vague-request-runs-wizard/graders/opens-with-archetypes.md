The user gave a vague, exploratory request: "build something on XL1, maybe a
game, haven't decided."

PASS if the response begins planning with the user — it offers a short set of
dApp shapes or archetypes to choose from (for example a hidden-move game,
prediction market, token, collectible, indexer) or asks which shape they have
in mind — and does not scaffold or lay out a full build.

FAIL if it starts scaffolding, presents a complete project plan or file tree as
though the spec were settled, or picks an archetype for the user without
offering a choice.
