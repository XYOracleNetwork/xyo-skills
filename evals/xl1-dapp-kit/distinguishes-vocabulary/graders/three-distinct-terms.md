The user asks how dapp-kit's "definition", "plan", and "incarnation" differ.

PASS if the answer gives each of the three a distinct meaning that is not
interchangeable with the others — roughly: what the application is, a resolved
intent for a particular target or configuration, and a running or instantiated
instance — and confirms they should not be used as synonyms.

FAIL if it treats any two of the three as the same thing, or says the
distinction does not matter.
